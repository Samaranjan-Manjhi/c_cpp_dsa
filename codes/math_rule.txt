------------------------------
1. NUMBER THEORY BASICS
------------------------------
GCD (Euclid's Algorithm):
    gcd(a, b) = gcd(b, a % b),   gcd(a, 0) = a
    C++: __gcd(a, b)   (in <algorithm> or <numeric>)
    C++17: std::gcd(a, b), std::lcm(a, b)   (in <numeric>)

LCM:
    lcm(a, b) = (a * b) / gcd(a, b)
    (Use a / gcd(a,b) * b to avoid overflow)

Extended Euclid:
    a*x + b*y = gcd(a, b)
    Used for modular inverse when mod is not prime.

Modular Arithmetic:
    (a + b) % m = ((a % m) + (b % m)) % m
    (a - b) % m = ((a % m) - (b % m) + m) % m
    (a * b) % m = ((a % m) * (b % m)) % m
    (a / b) % m = (a * modInverse(b, m)) % m   [NOT simple division]

Modular Exponentiation (Fast Power):
    pow(a, b) % m  ->  O(log b)
    long long power(long long a, long long b, long long m) {
        long long res = 1; a %= m;
        while (b > 0) {
            if (b & 1) res = (res * a) % m;
            a = (a * a) % m;
            b >>= 1;
        }
        return res;
    }

Modular Inverse:
    If m is prime (Fermat's Little Theorem):
        a^(-1) % m = a^(m-2) % m
    If m is not prime, use Extended Euclidean Algorithm.

Fermat's Little Theorem:
    a^(p-1) ≡ 1 (mod p)   if p is prime and gcd(a, p) = 1

Euler's Totient Function φ(n):
    Counts numbers <= n that are coprime to n.
    φ(n) = n * Π(1 - 1/p) for each prime p dividing n
    Euler's theorem: a^φ(n) ≡ 1 (mod n), if gcd(a,n)=1

Sieve of Eratosthenes (all primes up to N): O(N log log N)
    vector<bool> is_prime(N+1, true);
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i*i <= N; i++)
        if (is_prime[i])
            for (int j = i*i; j <= N; j += i)
                is_prime[j] = false;

Prime factorization (trial division): O(sqrt(N))
    for (int i = 2; i*i <= n; i++)
        while (n % i == 0) { factors.push_back(i); n /= i; }
    if (n > 1) factors.push_back(n);

Number of divisors:
    If n = p1^e1 * p2^e2 * ... * pk^ek
    d(n) = (e1+1)(e2+1)...(ek+1)

Sum of divisors:
    sigma(n) = Π ( (p_i^(e_i+1) - 1) / (p_i - 1) )

------------------------------
2. COMBINATORICS
------------------------------
Factorial:
    n! = n * (n-1) * (n-2) * ... * 1,   0! = 1

Permutations (order matters):
    nPr = n! / (n-r)!

Combinations (order doesn't matter):
    nCr = n! / (r! * (n-r)!)
    nCr = nC(n-r)
    Pascal's Triangle: C(n, r) = C(n-1, r-1) + C(n-1, r)

Combination with modulo (precompute factorials):
    fact[i] = fact[i-1] * i % MOD
    nCr % MOD = fact[n] * modInverse(fact[r], MOD) % MOD
                        * modInverse(fact[n-r], MOD) % MOD

Number of ways to distribute n identical items into r groups:
    Stars and Bars: C(n + r - 1, r - 1)

Catalan Number:
    C_n = (2n)! / ((n+1)! * n!) = C(2n, n) / (n+1)
    Used in: balanced parentheses, BST count, triangulation.

Derangement (no element in original position):
    D(n) = (n-1) * (D(n-1) + D(n-2)),  D(0)=1, D(1)=0

Binomial Theorem:
    (x + y)^n = Σ C(n, k) * x^(n-k) * y^k   for k = 0..n

------------------------------
3. BIT MANIPULATION FORMULAS
------------------------------
Check if number is power of 2:
    (n & (n-1)) == 0   (n > 0)

Count set bits:
    __builtin_popcount(n)        // int
    __builtin_popcountll(n)      // long long

Get i-th bit:          (n >> i) & 1
Set i-th bit:           n | (1 << i)
Clear i-th bit:         n & ~(1 << i)
Toggle i-th bit:        n ^ (1 << i)
Clear lowest set bit:   n & (n - 1)
Isolate lowest set bit: n & (-n)
XOR of 1 to n:
    n%4==0 -> n
    n%4==1 -> 1
    n%4==2 -> n+1
    n%4==3 -> 0

------------------------------
4. SEQUENCES & SERIES
------------------------------
Arithmetic Progression (AP):
    a_n = a + (n-1)*d
    Sum = n/2 * (2a + (n-1)*d) = n/2 * (first + last)

Geometric Progression (GP):
    a_n = a * r^(n-1)
    Sum (r != 1) = a * (r^n - 1) / (r - 1)
    Infinite sum (|r| < 1) = a / (1 - r)

Sum of first n natural numbers:
    n(n+1)/2

Sum of first n odd numbers (1 + 3 + 5 + ... + (2n-1)):
    Sum = n^2

Sum of first n even numbers (2 + 4 + 6 + ... + 2n):
    Sum = n(n+1)

nth odd number:  2n - 1
nth even number: 2n

Sum of squares:
    n(n+1)(2n+1)/6

Sum of cubes:
    [n(n+1)/2]^2

Fibonacci:
    F(n) = F(n-1) + F(n-2),  F(0)=0, F(1)=1
    Matrix exponentiation form:
    [[1,1],[1,0]]^n = [[F(n+1),F(n)],[F(n),F(n-1)]]
    (compute in O(log n) via fast matrix power)

------------------------------
5. GEOMETRY
------------------------------
Distance between two points:
    d = sqrt((x2-x1)^2 + (y2-y1)^2)

Slope of a line:
    m = (y2-y1) / (x2-x1)

Area of triangle (coordinates):
    Area = |x1(y2-y3) + x2(y3-y1) + x3(y1-y2)| / 2

Shoelace formula (polygon area, n vertices):
    Area = 0.5 * |Σ (x_i * y_(i+1) - x_(i+1) * y_i)|

Circle:
    Area = pi * r^2
    Circumference = 2 * pi * r

Pythagoras Theorem:
    c^2 = a^2 + b^2

Law of Cosines:
    c^2 = a^2 + b^2 - 2ab*cos(C)

Dot product:
    a . b = |a||b|cos(theta) = ax*bx + ay*by

Cross product (2D, gives orientation/area*2):
    a x b = ax*by - ay*bx

------------------------------
6. LOGARITHMS & EXPONENTS
------------------------------
log_b(x) = ln(x) / ln(b)          // change of base
log(a*b) = log(a) + log(b)
log(a/b) = log(a) - log(b)
log(a^n) = n * log(a)
a^log_a(x) = x

C++ functions (in <cmath>):
    log(x)   -> natural log (base e)
    log2(x)  -> base 2
    log10(x) -> base 10
    pow(a, b), sqrt(x), cbrt(x), exp(x)

Number of digits of n in base 10:
    digits = floor(log10(n)) + 1

------------------------------
7. PROBABILITY & STATISTICS
------------------------------
P(A or B) = P(A) + P(B) - P(A and B)
P(A and B) = P(A) * P(B)            // if independent
P(A | B) = P(A and B) / P(B)        // conditional

Expected value:
    E(X) = Σ x_i * P(x_i)

Mean:      sum(x_i) / n
Variance:  Σ(x_i - mean)^2 / n
Std Dev:   sqrt(Variance)

------------------------------
8. MATRIX OPERATIONS
------------------------------
Matrix multiplication (A: n x m, B: m x p -> C: n x p):
    C[i][j] = Σ_k A[i][k] * B[k][j]

Matrix exponentiation (for recurrences), O(k^3 log n):
    Represent recurrence as matrix, then fast-power it
    (used for Fibonacci, linear recurrences, DP speedups)

Determinant (2x2):
    det = ad - bc   for [[a,b],[c,d]]

9. USEFUL CONSTANTS & TRICKS
------------------------------
INT_MAX   = 2147483647          (~2.1 * 10^9)
INT_MIN   = -2147483648
LLONG_MAX = 9223372036854775807  (~9.2 * 10^18)
double pi = 3.14159265358979323846  (or use acos(-1.0))

Overflow-safe multiply check (a * b > LIMIT):
    if (a != 0 && b > LIMIT / a) // overflow

Ceil division of ints (a / b rounded up), a,b > 0:
    (a + b - 1) / b

Check overflow-free average of two ints:
    mid = low + (high - low) / 2   // instead of (low+high)/2
