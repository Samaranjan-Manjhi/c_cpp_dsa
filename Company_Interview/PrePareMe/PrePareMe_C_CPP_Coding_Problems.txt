## 1. Arrays & Matrix Operations

### Easy
1. Write a C program to find the largest and smallest elements in an array.
2. Implement an algorithm to reverse an array in-place.
3. Write a program to find the second largest element in an unsorted array.
4. Count the frequency of each element in an integer array.
5. Check if an array is sorted in ascending order.
6. Remove duplicate elements from a sorted array in $O(1)$ extra space.
7. Find the missing number in an array containing numbers from $1$ to $N$.
8. Move all zeros to the end of the array while maintaining the relative order of non-zero elements.
9. Implement left rotation of an array by $K$ positions.
10. Implement right rotation of an array by $K$ positions.
11. Find the intersection of two integer arrays.
12. Find the union of two sorted integer arrays.
13. Compute the prefix sum array for a given input array.
14. Check if an array contains a pair with a given sum $S$ (Two Sum problem).
15. Count the number of even and odd elements in an array.
16. Find the element that appears only once in an array where every other element appears twice.
17. Merge two sorted arrays into a single sorted array.
18. Find the maximum difference between two elements such that the larger element appears after the smaller element.
19. Given an array of $N$ integers, check if there exists a subarray with a sum equal to 0.
20. Transpose a square matrix in-place.
21. Compute the sum of primary and secondary diagonals of an $N \times N$ matrix.
22. Check if two matrices are identical.
23. Find the maximum element in each row of a matrix.
24. Count the number of negative numbers in a row-wise and column-wise sorted matrix.
25. Find the Majority Element in an array (element appearing more than $N/2$ times).

### Medium
26. Implement Kadane's Algorithm to find the contiguous subarray with the maximum sum.
27. Find all unique triplets in an array that sum up to zero (3Sum problem).
28. Rotate an $N \times N$ matrix by 90 degrees clockwise in-place.
29. Print a matrix in spiral order.
30. Search for a value in an $M \times N$ matrix where rows and columns are sorted (Matrix Search).
31. Rearrange an array such that positive and negative numbers alternate.
32. Find the equilibrium index of an array (where sum of left elements equals sum of right elements).
33. Find the longest contiguous subarray with an equal number of 0s and 1s.
34. Find the contiguous subarray with the maximum product.
35. Merge overlapping intervals given as an array of pairs.
36. Given an array of non-negative integers representing heights, calculate how much rainwater can be trapped (Trapping Rainwater).
37. Implement Next Permutation in C++ (find the lexicographically next greater permutation).
38. Find the majority element that appears more than $\lfloor N/3 \rfloor$ times.
39. Find the contiguous subarray with a sum equal to a target $K$.
40. Calculate the maximum length of a subarray whose sum is divisible by $K$.
41. Set entire matrix rows and columns to zero if an element is zero (Set Matrix Zeroes).
42. Given an unsorted array, find the length of the longest consecutive elements sequence.
43. Sort an array consisting of only 0s, 1s, and 2s without using any sorting algorithm (Dutch National Flag problem).
44. Find the minimum size subarray sum that is greater than or equal to a target value.
45. Implement Pascal's Triangle generation up to $N$ rows.
46. Find the smallest missing positive integer in an unsorted array in $O(N)$ time and $O(1)$ auxiliary space.
47. Count the number of subarrays having XOR sum equal to $K$.
48. Find the maximum path sum starting from any cell in the top row to any cell in the bottom row of a grid.
49. Implement matrix multiplication for two arbitrary-sized matrices.
50. Rearrange array elements such that $A[i] \ge A[i-1]$ for even $i$ and $A[i] \le A[i-1]$ for odd $i$ (Wave Array).

### Hard
51. Compute the maximum sum of a rectangle in a 2D matrix (2D Kadane's Algorithm).
52. Given an array of $N$ integers, find the maximum value of $|A[i] - A[j]| + |i - j|$.
53. Count total number of inversions in an array using Merge Sort logic.
54. Find the median of two sorted arrays of different sizes in $O(\log(\min(M, N)))$ time.
55. Implement the Sliding Window Maximum problem using a Deque.
56. Find the maximum area rectangle formed by 1s in a binary matrix.
57. Solve the First Missing Positive integer problem in $O(N)$ time and $O(1)$ space.
58. Given an array, find the maximum value of $A[i] - A[j] + A[k] - A[l]$ such that $i < j < k < l$.
59. Count the number of subarrays with at most $K$ distinct integers.
60. Find the maximum sum non-overlapping subarrays of specified lengths.

### Hard

### Hard
